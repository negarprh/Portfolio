# Engineering map

Last reconciled: 2026-09-27. Use this file to locate implementation ownership and proportional verification without loading the career or design context unless the task needs them.

## Stack and runtime

- Next.js 16.3.4 App Router, React 19.3, TypeScript, Tailwind CSS 4.
- This Next.js version may differ from model knowledge. Before changing Next.js code, read the relevant local guide under `node_modules/next/dist/docs/` and follow its deprecations.
- The page is server-rendered. Do not convert it to a static export.
- `app/page.tsx` and the GitHub request use hourly ISR (`revalidate = 3600`). `lib/github.ts` has a five-second timeout and returns `null` on failure.
- Design tokens live in CSS rather than a Tailwind theme. Styles load in this order: `globals.css`, `book-material.css`, `chapters.css`, `makeover.css`; later overrides are intentional.
- Next.js discovers `app/icon.svg`, `app/favicon.ico` (16/32/48px), and `app/apple-icon.png` (180px) automatically. After editing the SVG master, regenerate raster fallbacks with `node scripts/generate-favicon.cjs`.
- Share previews use `app/opengraph-image.png`, a 1200×630 screenshot of the settled front cover, with accessible text in `app/opengraph-image.alt.txt`. Next.js supplies the Open Graph image and Twitter image fallback; the layout requests a large Twitter card. Recapture the image after cover design changes. `NEXT_PUBLIC_SITE_URL` can set the canonical origin for custom domains; otherwise the Vercel production/deployment host is used, with localhost for local development.

## Data and fallback contracts

- `lib/content.ts` is the rendered source for structured roles, projects, skills, and links. Career meaning and provenance are recorded in `CAREER.md`; keep them synchronized.
- The approved public email is stored in `lib/content.ts`. Negar confirmed on 2026-10-12 that Resume links remain omitted; do not add a placeholder. Contact fields need no environment configuration. Never commit secrets.
- GitHub stars are server-fetched public data; no client polling and no invented fallback number.
- Enhanced interior materials are gated by `html[data-book-enhanced]`. Static fallbacks remain readable without it.
- `lib/book-stage.ts` measures full reading blocks after fonts and images load and on resize, applies a static layout scale only when necessary, and centers them within symmetric bounds. Teardown restores their original inline styles. Do not reintroduce nested page scrolling or replace original copy with summaries.
- Fixed visible pages and the turn stage use dynamic viewport height; a hidden fixed `100svh` probe supplies stable runway heights and turn distances. The probe is removed on teardown. `BookMotion` connects phone/wheel/index controllers to synchronized seeks; keyboard/programmatic response, immediate deep links, and browser history remain available.
- The final slot uses the larger of small and visible viewport height so contact remains reachable after browser chrome retracts. `tests/tall-phone.spec.ts` explicitly simulates this height mismatch without claiming to reproduce real browser chrome.
- `lib/phone-turns.ts` owns controlled phone swipes with 0.95-viewport drag travel, frame-based speed limiting, short-swipe rollback, 300–850ms release settling, and braking by a new touch. `lib/wheel-turns.ts` applies 75% vertical wheel/trackpad gain, a shared 850ms full-turn pace, bounded pending travel, and reversal cancellation. Shared constants live in `lib/book-effects.ts`. Both controllers synchronize document/rendered positions and cancel for explicit navigation, preference changes, and teardown. Native zoom/horizontal/index input is excluded. Reduced-motion/no-JS retain native scrolling.
- Large-monitor paper widths and fore-edge insets share `--wide-book-width` in `makeover.css`. `book-stage.ts` scales reading content up to 1.8× on spacious screens before applying height fitting. `tests/wide-book.spec.ts` checks proportions and fore-edge alignment from 1920×1080 through 5120×1440; the page-fit matrix also covers large monitors. `tests/native-page-stops.spec.ts` checks controlled fast swipes, reversal, touch-down braking, taps, and reduced-motion removal.
- Decorative turning-sheet snapshots are inert and sanitized, including removal of IDs and boundary attributes. Original pages retain semantic content and links. Source styles preserve chapter-scoped layouts inside clipped front/back sheet strips.
- Experience SVG chips load eagerly so requests begin during the opening; other deferred assets keep their existing loading policy.
- `.book-opening`, `.opening-runway`, and introduction scroll margins coordinate the enhanced cover overlap with native anchor landing. Do not remove one in isolation.
- Index and inline chapter links use measured document runway positions, preserve hash history and focus, and bypass fixed-target native anchor drift. Native fallback links remain available without JavaScript.
- `lib/index-turns.ts` runs one 360ms effect, independent of chapter distance. `book-stage.ts.transition` pairs arbitrary current/destination surfaces through the existing sheet renderer; normal scroll updates retain adjacent-page geometry. Sheet caching tracks both outgoing and incoming indices so returning to normal scrolling rebuilds the correct pair. Native scroll stays fixed until arrival/interruption. `data-book-navigating` suppresses ordinary stage repaint/hash replacement and extends `settleBook` verification. Focus moves on arrival; reduced-motion changes finish and re-land against static geometry. The `booknavigationstart` event settles cover entrances. `tests/index-turns.spec.ts` checks brief timing, that only source/destination pages are visible, stationary native scroll, both directions, hashes, focus, interruption, and live preference changes.
- Both exposed fore-edges share `public/images/page-block.svg`, a static, non-tiled sheet texture. Their dimensions and scroll-driven transforms remain owned by the existing CSS and motion code.

## Verification matrix

| Change                  | Minimum targeted checks                                                | Broader checks before handoff                                    |
| ----------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Copy/data only          | Search for stale old values; relevant Playwright content assertions    | `npm run typecheck`; build if server rendering/data changed      |
| Component/TypeScript    | Relevant spec plus `npm run typecheck`                                 | `npm run build`, then full `npm test` for cross-cutting behavior |
| CSS/layout/material     | Relevant viewport specs and screenshots                                | Full test suite plus visual review at desktop/mobile sizes       |
| Motion/enhancement      | Motion, bidirectional, reduced-motion, no-JS, spread readability specs | Full suite and generated review captures                         |
| GitHub fetch/ISR        | Unit/integration path, success and `null` fallback                     | Production build                                                 |
| Signature/path geometry | Run signature review and cover-signature spec                           | Desktop/mobile video or frame inspection                         |

Primary suites include `book.spec.ts`, `book-material.spec.ts`, `chapters.spec.ts`, `makeover.spec.ts`, `bidirectional.spec.ts`, `premium-motion.spec.ts`, `spread-readability.spec.ts`, and `ink-progress.spec.ts`. Tests expect a server at `http://localhost:3000`, overridable with `BOOK_TEST_BASE_URL`, plus installed Playwright Chromium.

Useful review scripts:

- `node scripts/review-jackets.cjs` for front/back desktop comparisons and mobile covers.
- `node scripts/review-chapters.cjs` for adjacent content pages and divider views.
- `node scripts/review-signature.cjs` for signature videos and timing traces.

Generated output belongs in ignored `test-results/`; do not treat it as source.

`lib/book-effects.ts` owns the shared turn-travel and scroll-response constants. `tests/ink-progress.spec.ts` checks identical interior bounds and reversible curvature; `tests/premium-motion.spec.ts` checks that cover and chapter geometry agree; `tests/spread-readability.spec.ts` checks every spread without nested scrolling. `tests/page-fit.spec.ts` verifies preserved paragraphs, viewport bounds, centered reading blocks, and teardown across small phones, tablets, landscape, and desktop.

`tests/projects.spec.ts` verifies the three-project selection, public link destinations and attributes, desktop/mobile spread reversals, reduced motion, and no-JS rendering. Project data owns explicit GitHub/live URLs and optional existing artwork; do not infer a deployment URL from a repository name.

`tests/skills.spec.ts` verifies the approved 31-item inventory in six categories across two Skills spreads, four viewport sizes, decorative monochrome logos, overflow, reversed turns, reduced motion, and no-JS content. Skills layout and optical logo sizing are scoped to `#skills` in `app/makeover.css`.

`tests/tall-phone.spec.ts` covers tall touch viewports, height changes, programmatic phone seeks without leftover inertia, reversal, and removed availability. Page-fit coverage includes 384×824, 412×915, 412×1000, and 430×960 in addition to the existing matrix. These are simulated browser checks, not physical Samsung device validation.

## Documentation maintenance

Education uses one program heading/credential group and one institution/context group in `components/education.tsx`. `tests/education-layout.spec.ts` checks desktop/phone layouts and repeated deep-page measurements. `book-stage.ts` temporarily preserves document height while measuring natural content, preventing browser scroll clamping near the last pages when the natural layout is shorter than the enhanced runways.

`tests/input-pacing.spec.ts` samples actual phone flick frames and large trackpad deltas, verifies that a turn remains visible over time, and checks reversal/reduced-motion fallback. `tests/motion-helpers.ts` waits for `data-book-input-moving` to clear as well as visual/native alignment, so tests do not treat a paced turn as finished while it is still moving.

Project action placement and evidence grouping live in `components/selected-work.tsx`; phone layouts and action emphasis are scoped in `app/makeover.css`. `book-stage.ts` hides standalone running heads while the physical sheet is turning. `tests/chapter-heads.spec.ts` checks forward/reverse chapter boundaries on desktop and phone; project tests preserve action destinations and their placement before the description.

`tests/native-page-stops.spec.ts` now exercises controlled CDP swipes rather than native fling physics: fast gestures move one leaf, reversal returns one leaf, a held finger does not drift, cover/art/stage stay at top zero during the first turn, short swipes roll back, and touching again brakes settling.

`book-motion.tsx` synchronizes the URL fragment to the active index entry using replaceState while preserving framework history state. Explicit selections still push history entries. Home targets `#top` at scroll position zero; `book-stage.ts` marks the cover as Home. Cover artwork stretches to its fixed surface height, and its content uses dynamic viewport height. `tests/navigation-state.spec.ts` checks scroll/reload consistency and Home.
