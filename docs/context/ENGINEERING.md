## Stack and runtime

- Next.js 16.3.4 App Router, React 19.3, TypeScript, Tailwind CSS 4.
- This Next.js version may differ from model knowledge. Before changing Next.js code, read the relevant local guide under `node_modules/next/dist/docs/` and follow its deprecations.
- The page is server-rendered. Do not convert it to a static export.
- `app/page.tsx` and the GitHub request use hourly ISR (`revalidate = 3600`). `lib/github.ts` has a five-second timeout and returns `null` on failure.
- Design tokens live in CSS rather than a Tailwind theme. Styles load in this order: `globals.css`, `book-material.css`, `chapters.css`, `makeover.css`, `illustrations.css`; later overrides are intentional.
- Next.js discovers `app/icon.svg`, `app/favicon.ico` (16/32/48px), and `app/apple-icon.png` (180px) automatically. After editing the SVG master, regenerate raster fallbacks with `node scripts/generate-favicon.cjs`.
- Share previews use `app/opengraph-image.png`, a 1200×630 screenshot of the settled front cover, with accessible text in `app/opengraph-image.alt.txt`. Next.js supplies the Open Graph image and Twitter image fallback; the layout requests a large Twitter card. Recapture the image after cover design changes. `NEXT_PUBLIC_SITE_URL` can set the canonical origin for custom domains; otherwise the Vercel production/deployment host is used, with localhost for local development.

## Data and fallback contracts

- `lib/content.ts` is the rendered source for structured roles, projects, skills, and links. Career meaning and provenance are recorded in `CAREER.md`; keep them synchronized.
- The approved public email is stored in `lib/content.ts`. Negar confirmed on 2026-10-12 that Resume links remain omitted; do not add a placeholder. Contact fields need no environment configuration. Never commit secrets.
- GitHub stars are server-fetched public data; no client polling and no invented fallback number.
- Enhanced interior materials are gated by `html[data-book-enhanced]`. Static fallbacks remain readable without it.
- `lib/book-stage.ts` measures full reading blocks after fonts and images load and on resize, applies a static layout scale only when necessary, and centers them within symmetric bounds. Teardown restores original inline styles. Normal spreads retain the complete fitted page; do not replace original copy with summaries. Exceptionally oversized content that remains taller than the paper starts at its readable top and uses controlled reading scroll, preserving its offset on remeasurement. `lib/reading-scroll.ts` detects remaining content in the actual input surface. Wheel/touch controllers consume that entire gesture for reading, so arriving at the edge cannot spill into a turn; a fresh gesture at the edge navigates. Stage overflow detection runs during measurement, not per animation frame. Enhanced runways disable native scroll anchoring while their measurements change; no-JS/reduced motion keep native behavior.
- Fixed visible pages and the turn stage use dynamic viewport height; a hidden fixed `100svh` probe supplies stable runway heights and turn distances. The probe is removed on teardown. `BookMotion` connects phone/wheel/index controllers to synchronized seeks; keyboard/programmatic response, immediate deep links, and browser history remain available.
- The final slot uses the larger of small and visible viewport height so contact remains reachable after browser chrome retracts. `tests/tall-phone.spec.ts` explicitly simulates this height mismatch without claiming to reproduce real browser chrome.
- `lib/phone-turns.ts` owns vertical phone/coarse-pointer touch gestures with 0.55-viewport drag travel, 8px/1.25-ratio axis recognition, 48px-or-7%-viewport commitment, frame pacing, short/cancelled-swipe rollback, 180–520ms settling and touch-down braking. `lib/wheel-turns.ts` recognizes 4 normalized pixels of intent, then completes one adjacent stop over a 520ms full turn. Its independent gesture state suppresses momentum after arrival, rearms after 220ms responsive-frame silence or renewed intent, and retraces the active leaf on reversal. Gradual renewed ramps accumulate above a low tail valley; isolated coalesced bumps during a turn cannot restart it. Nonincreasing tails across short pauses remain consumed. A scroll listener registered before the motion listener restores the controlled vertical coordinate when diagonal/native noncancelable defaults try to bypass it. Horizontal scrolling itself stays native. Keyboard, zoom and explicit navigation are excluded/cancel ownership. Both controllers skip only stationary runway space, synchronize document/rendered positions, and cancel for changed geometry, preferences and teardown. Cancellation clears the shared moving marker only when that controller owns movement. Reduced-motion/no-JS retain native scrolling.
- `app/page.tsx` renders the phone swipe instruction directly in the opening link. CSS selects it by width or primary pointer, independently of hydration, timers, and session storage. `components/navigation-hint.tsx` owns the desktop-only annotation, which observes the cover entrance, retires after 4.6 seconds or on navigation, and records its appearance for the tab. The stage removes the annotation from snapshots. Reduced motion disables its animation.
- `book-stage.ts` freezes computed styles once into shared generated CSS rules, collecting authored properties plus inline fitting, resolved grid tracks and text fill; root/pseudo surfaces retain complete material declarations. Important frozen rules preserve the former inline specificity, while visibility inherits from the physical stage and dynamic snapshot geometry uses inline important overrides. Batched reads precede rule insertion. Each face copies only intersecting subtrees; fixed layout placeholders retain out-of-strip blocks, while inline text/line breaks and baseline siblings stay intact. Descendant bounds include absolute artwork. The shared stylesheet is replaced only when old faces are removed, and removed entirely on teardown/reduced motion. Cover copies normalize entrance lettering before warming; original semantic content is untouched.
- `makeover.css` compacts the existing cover at heights of 450px and below so the opening link and its annotation remain visible in phone landscape. It retains the same fonts/elements and includes safe-area spacing. Guidance tests check clearance and viewport bounds at 320×568, 390×844, 844×390 and 1440×900.
- `BookMotion.measure` remaps the same reading position when runway geometry changes during resize/orientation changes and cancels outdated input destinations. Ordinary font/image remeasurement with unchanged stops does not interrupt a gesture.
- Large-monitor paper widths and fore-edge insets share `--wide-book-width` in `makeover.css`. `book-stage.ts` scales reading content up to 1.8× on spacious screens before applying height fitting. `tests/wide-book.spec.ts` checks proportions and fore-edge alignment from 1920×1080 through 5120×1440; the page-fit matrix also covers large monitors. `tests/native-page-stops.spec.ts` checks controlled fast swipes, reversal, touch-down braking, taps, and reduced-motion removal.
- Decorative turning-sheet snapshots are inert and sanitized, including removal of IDs and boundary attributes. Original pages retain semantic content and links. Source styles preserve chapter-scoped layouts inside clipped front/back sheet strips.
- Experience SVG chips load eagerly so requests begin during the opening; other deferred assets keep their existing loading policy.
- `.book-opening`, `.opening-runway`, and introduction scroll margins coordinate the enhanced cover overlap with native anchor landing. Do not remove one in isolation.
- Index and inline chapter links use measured document runway positions, preserve hash history and focus, and bypass fixed-target native anchor drift. Native fallback links remain available without JavaScript.
- `lib/index-turns.ts` runs one 360ms effect, independent of chapter distance. `book-stage.ts.transition` pairs arbitrary current/destination surfaces through the existing sheet renderer; normal scroll updates retain adjacent-page geometry. Sheet caching tracks both outgoing and incoming indices so returning to normal scrolling rebuilds the correct pair. Native scroll stays fixed until arrival/interruption. `data-book-navigating` suppresses ordinary stage repaint/hash replacement and extends `settleBook` verification. Focus moves on arrival; reduced-motion changes finish and re-land against static geometry. The `booknavigationstart` event settles cover entrances. `tests/index-turns.spec.ts` checks brief timing, that only source/destination pages are visible, stationary native scroll, both directions, hashes, focus, interruption, and live preference changes.
- Both exposed fore-edges share `public/images/page-block.svg`, a static, non-tiled sheet texture. Their dimensions and scroll-driven transforms remain owned by the existing CSS and motion code.
- Phone depth styling is scoped to the existing mobile media queries in `book-material.css`, `chapters.css`, and `makeover.css`; `book-stage.ts` applies mobile-only flex/lighting coefficients. `scripts/review-phone-depth.cjs before|after` captures resting and intermediate turn frames plus fitting measurements at 320px, 390px, 412px, and desktop.
